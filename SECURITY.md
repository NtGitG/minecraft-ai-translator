# Security Policy

## Supported Versions

MineGlot is maintained for the latest public release only.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| Older releases | No |

## Reporting a Vulnerability

Please do not report security issues publicly if the report contains sensitive details, API keys, private server addresses, or a reproducible exploit.

Use GitHub security reporting when available:

https://github.com/NtGitG/minecraft-ai-translator/security/advisories/new

If private reporting is not available, open a GitHub issue with a short non-sensitive summary and mention that it is security-related:

https://github.com/NtGitG/minecraft-ai-translator/issues

Please include:

- MineGlot version
- Minecraft Forge version
- Java version
- What the security concern is
- Steps to reproduce, if they do not expose private information

## API Keys

MineGlot is a client-side mod. API keys should stay on the user's computer and must never be posted in GitHub issues, logs, screenshots, or crash reports.

If an API key was exposed, revoke it immediately from the provider dashboard and create a new one.
